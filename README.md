## how to use
> If you want to download in native environment 
>* run ```pip install -r requirements.txt```

>If you want to run in a virtual environment 
>* First make sure you have venv installed in your python install ```pip install venv```
>* then, to activate the ML environment, run ```source ML/bin/activate``` for linux
> and, ```source ML/bin/Activate.ps1``` for windows

>Enjoy
