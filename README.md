## how to use
[Option_1]
> If you want to download in native environment 
>* run ```pip install -r requirements.txt```

[Option_2]
>If you want to run in a virtual environment 
>* First make sure you have venv installed in your python install ```pip install venv```
>*, create your virtual env by tping in your terminal:: ```python -m <virtual environment name>```
>* then, to activate the ML environment, run ```source yourVirtualEnvionmentName/bin/activate``` for linux
> and, ```source yourVirtualEnvName/bin/Activate.ps1``` for windows

>Enjoy
